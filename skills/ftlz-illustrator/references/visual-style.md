# Visual Style

Use this baseline for all `ftlz-illustrator` prompts unless the user overrides it.

## Character Reference

- Refer to the user's uploaded character image as "随同上传的角色参考图".
- State that the reference image is only for the character asset.
- Preserve the character's identity, hairstyle, clothing, proportions, and temperament.
- Redraw the character naturally inside the new scene.
- Do not reproduce a character turnaround sheet, multi-view layout, pose grid, or the reference image composition.

## Illustration Baseline

Use a retro, rounded, humorous sci-fi comic feeling:

- Q-version character proportions
- clean thick outlines
- rounded shapes
- bright but restrained color blocks
- handmade arrows and small visual symbols
- light hand-drawn texture
- original whimsical inventions when tools or machines are needed
- simple, readable public-account illustration composition

Keep the style as visual traits. Do not ask for a direct copy of any existing artist, manga character, brand machine, or copyrighted visual design.

## Background

Default to pure white:

- white background
- generous blank space
- no paper texture
- no dark background
- no complex gradients
- no decorative clutter

## Character Roles

Choose one role that clarifies the idea:

- Explainer: points at nodes, diagrams, or labels.
- Operator: feeds input into a tool, machine, or workflow.
- Observer: looks through a magnifier or studies a detail.
- Guide: points along a route, timeline, or path.
- Judge: compares two sides or chooses between options.
- Discoverer: finds the hidden relationship or key clue.
